# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and patient.
- Assume good intent.
- Keep discussion about the project.

Harassment, insults and personal attacks are not accepted anywhere this project is represented: issues, pull
requests, discussions and reviews.

## Reporting

Report unacceptable behaviour to the maintainer, Ahsan Ilyas (GitHub `ahsanilya-s`). Two private ways to do it:

- [Open a private report](https://github.com/ahsanilya-s/claude-desktop-multi-instance/security/advisories/new),
  with a title that starts with "Conduct:". Only the maintainer can see it.
- [Report abuse to GitHub](https://github.com/contact/report-abuse).

Reports are kept confidential. The maintainer may edit or remove comments, and block people who break these rules.
