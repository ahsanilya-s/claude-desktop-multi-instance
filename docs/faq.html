FAQ and troubleshooting

For claude-desktop-multi-instance, a free script that runs several Claude Desktop accounts side by side on Windows. Unofficial, not affiliated with Anthropic.

Troubleshooting

Claude 2 is still signed out, or the sign-in finished in my normal Claude

Google and browser sign-in return through a claude:// link, which Windows hands to the first Claude that is running (#98549). In Claude 2, sign in with your email address and type the code from the email into the Claude 2 window. If the first button opens your browser, look for the email option, which may be under “Sign in another way”.

Claude 2 opened with my normal account

It was started without its own data folder, for example when Claude restarted itself after an update (#104138). Close that window and open Claude 2 from its desktop shortcut or the picker.

Claude 2 shows a blank white window

In the picker, select Claude 2, click Quit, then open it again. On the maintainer's PC this happened after Claude 2 had been hidden in the tray for a long time while memory was low. Quitting instances you are not using avoids it.

Clicking the shortcut does nothing

An open instance only hidden in the tray comes forward when you click its shortcut. If nothing appears:

  • Run -List to see whether it is open, then Quit it in the picker and open it again.
  • Check that the tool's folder still exists.
  • If you moved the folder, run -Setup again from its new place.
The window title stays “Claude”

The title helper starts once the window exists, which can take up to 30 seconds. Check that bin\ClaudeTitleKeeper-v1.exe exists in the tool's folder, and that antivirus did not block it. It is compiled on your PC, so it is unsigned.

“Claude Desktop is not installed for this Windows account”

Install Claude Desktop from claude.ai/download while you are signed in to Windows as yourself, then run -Setup.

“Running scripts is disabled on this system”

Use the full command, which allows this one script without changing your system policy:

powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\ClaudeInstances\Open-ClaudeInstance.ps1" -Setup

The desktop shortcuts use the same method.

The download fails with “Could not create SSL/TLS secure channel”

This happens on older Windows 10. Run this line first, then the install commands again:

[Net.ServicePointManager]::SecurityProtocol = 'Tls12'
The script says PowerShell 7 is not supported

Run it with Windows PowerShell (powershell.exe), which is built into Windows. The picker, the app lookup and the title helper need it.

Questions

Can I use two Claude accounts at the same time in Claude Desktop on Windows?

Not with Claude Desktop alone; it runs one account per Windows user. This script starts extra copies of the installed app, each with its own data folder (via the --user-data-dir switch), so each copy can be signed in to a different account at the same time.

Why does signing in to the second instance finish in my normal Claude?

Google and browser sign-in return to the app through a claude:// link, and Windows hands that link to the first Claude that is running. In an extra instance, sign in with your email address and type the emailed code into that instance's window.

Is this an official Anthropic tool?

No. It is an independent open-source script (MIT licence) that starts the official Claude Desktop you already installed. It is not affiliated with or endorsed by Anthropic.

Does it modify Claude Desktop or my normal Claude?

No. It does not patch or inject into the app, and it never changes or quits your normal Claude. It starts the installed app with a separate data folder and renames the extra windows' titles.

Does it get around usage limits?

No. Each instance uses the account you sign in with, under that account's limits. Anthropic's Consumer Terms forbid sharing accounts, and its Usage Policy forbids using extra accounts to evade bans or detection. Use it only for accounts that are yours.

Can two instances use the same account?

Yes, just as you can use Claude on two devices. This is handy if you want two different MCP server setups.

Where does each instance keep its data?

  • Sign-in, settings, MCP configuration and cache: %APPDATA%\Claude-<Name>.
  • Claude's logs: %LOCALAPPDATA%\Claude-<Name>\logs.
  • The tool's own settings (numbers and labels): instances.json in the folder you installed the tool to.
  • Your chats: in your Claude account, as always.

How do I remove an instance?

  1. Quit it in the picker.
  2. Delete its desktop shortcut.
  3. Delete %APPDATA%\Claude-<Name> and %LOCALAPPDATA%\Claude-<Name>.
  4. Remove its entry from instances.json.

A one-step -Remove command is on the roadmap.

How do I uninstall the tool?

  1. Quit the extra instances.
  2. Delete the desktop shortcuts “Claude 2 …” and “Claude - choose instance”.
  3. Delete %USERPROFILE%\ClaudeInstances.
  4. Optional: delete each instance's data folders, as described above.

Does it work on macOS, Linux or with PowerShell 7?

No. It is for Windows 10 and 11 with Windows PowerShell 5.1. For macOS, see community projects such as claude-multiprofile and claude-fix.

Is it safe? What does it access?

  • It runs as you, without admin rights, and makes no network requests.
  • It reads an instance's config.json only to see whether a sign-in key is present. It never reads out or sends the token.
  • Its code is one readable file, and its title helper is compiled from source on your PC.

The full list is in SECURITY.md.
